# Brief: v0.1 — Infrastructure and stage

## Goal

A deployable, empty-but-correct foundation. A placeholder version of the final screen layout appears at a public URL, and every later version plugs into it.

## Build

1. Scaffold Vite + TypeScript (strict) in the current folder. Add ESLint, Prettier, Vitest, and the npm scripts listed in `CLAUDE.md`.
2. Create the folder structure from `CLAUDE.md`, with empty `index.ts` files where useful so the structure is visible.
3. Install Fontsource for Turret Road (500, 800) and Kode Mono (400, 700). Set up `src/styles/tokens.css` with the current palette and font variables.
4. **Stage:** a 1440 × 900 design stage that scales to fit the window (contain), centered, recalculated on resize. Below 1280 × 720 it keeps the scale for 1280 × 720 rather than shrinking further. Export a `toStageCoords(clientX, clientY)` helper from `src/core/stage.ts`, with a unit test.
5. **Layer stack:** all seven layers from `CLAUDE.md` as separate modules, rendered as labelled placeholder blocks using the sizes in `src/config/layout.config.ts`. Doors closed. Background bleeds past the stage on wide windows, with no hard edge visible.
6. **HUD:** logo text "SharpEye" + "orAI" (the second part in hazard orange), top center. Version label bottom center, injected from `package.json` at build time (show as `v0.1`).
7. **Debug overlay** toggled with the backtick key (`): shows the current scale factor, window size, and live stage coordinates of the mouse. Hidden by default.
8. Set `package.json` version to `0.1.0`. Write a short `README.md`: what the project is, how to run it, the link to the live site (placeholder for now).

## Git and deploy

- Initialize git. `.gitignore` covers node_modules, dist, .env files, OS files, and `assets-src/`.
- Remote: `https://github.com/<OWNER>/sharpeyeorai` (ask the owner for their username).
- This first time only, commit to `main` and push. From v0.2 on, work on branches.
- If pushing fails because GitHub isn't authenticated, stop and explain to the owner how to sign in (GitHub CLI `gh auth login` is the simplest). Never ask for or handle passwords or tokens yourself.
- After the push, tag `v0.1.0`.

## Done when

- `npm run dev` shows the placeholder stage, scaled correctly at 1280×720, 1440×900 and 2560×1440.
- `npm run build`, `npm run test` and `npm run lint` all pass.
- The backtick key toggles the debug overlay, and its coordinates match the design pixels at every window size.
- The code is on GitHub `main`, tagged `v0.1.0`.

## Out of scope

Scenes, the state machine, rounds, scoring, animations, real assets, sound. Those start in v0.2.

## After finishing

Tell the owner, step by step, how to import the repo into Vercel (Add New Project → import `sharpeyeorai` → framework preset Vite → Deploy), and what URL to expect.
