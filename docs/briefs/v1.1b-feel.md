## 1. Parallax (`src/fx/parallax.ts`)
- Input: the pointer position as −1…1 on each axis, where 0 is the viewport center.
- Layers and maximum offsets at ±1 (px, applied as `translate`):

| Layer | x at mouse left / right | y at mouse up / down |
|---|---|---|
| background (incl. the WebGL canvas) | −12 / +12 | −8 / +8 |
| outer frame shadow | +8 / −8 | +4 / −4 |
| inner frame shadow | +4 / −4 | +2 / −2 |

  The background follows the mouse; both shadows move against it.
- The shadows are already generated in code from the frame asset. Find the existing outer and inner shadow layers and apply the offsets to them. If only one shadow exists, ask the owner before inventing the second.
- **Smoothing:** frame-rate-independent exponential smoothing that settles in about 500ms, for a heavy, slightly floaty feel. No springy overshoot.
- **Mouse leaves the window:** the target returns to 0 and the layers drift slowly back to center, settling in about 1.5s.
- Combines with existing transforms (breathing, round 10 drop) without overriding them: compose the transforms, don't replace them.
- `prefers-reduced-motion`: parallax off.

## 2. System cursor (the metal pixel set)
Use CSS `cursor: image-set(url(...) 1x, url(...@2x) 2x) hotspotX hotspotY, <fallback>`. Hotspots, at 1× values:

| Cursor | Hotspot | Used for |
|---|---|---|
| default | 0 0 | Everywhere by default |
| pointer | 4 0 | Hover over buttons and links |
| pointer-down | 4 2 | While the mouse button is held over a button or link |
| not-allowed | 7 7 | Disabled buttons, and inside the screen while clicks are ignored during rounds (intro/outro), unless the Figma shows an inactive state for the custom cursor instead |

Provide native fallbacks (`default`, `pointer`, `not-allowed`) for browsers that reject the images.

## 3. Custom in-screen cursor (`src/ui/screenCursor.ts`)
**When it shows**
- Only while a round is active and accepting clicks, and only when the pointer is inside the screen **opening**.
- Never on the intro, the Initializing/loading screen, the score screen, or anywhere outside the opening.
- While it shows, the system cursor is hidden (`cursor: none` on the opening).

**Parts.** Build both as inline SVG from the Figma reference: the brackets and the central dot.
- **Brackets:** follow the pointer exactly, with no smoothing. The hotspot is their center.
- **Dot:** trails behind with a smoothed follow. The faster and farther the move, the larger the visible lag. The distance from the brackets' center is clamped to a **maximum of 40px**.
- **Spread:** bracket size grows with pointer speed, like an FPS crosshair. **Slow to spread, fast to recover:** use a longer attack and a short release, plus a maximum spread from Figma (or a sensible default if Figma doesn't show one).
- **Pressed and inactive states** as shown in Figma. If Figma doesn't show them, use a brief snap-in on click.
- The click position used for scoring is always the brackets' center (the real pointer), never the dot.
- `prefers-reduced-motion`: no lag and no spread.
- **Debug panel:** sliders for the dot lag, attack, release and max spread, plus a readout of pointer speed.

- **System Message "ALERT!":** orange variant. It replaces the current alert box in its existing position and timing (from v0.7).
- The API allows other messages later, for example `showChatMessage({ variant, title, body, anchor, durationMs })`.
- Same hand-drawn 2px border family as the sample tooltip. Corners, tail or pointer, padding and type per Figma.
- Rename the old "copied tooltip" everywhere to **chat message**, in code and in `CLAUDE.md`.

## 6. TV noise overlay (`src/fx/noise.ts`)
- A full-viewport layer above all scene and HUD layers, with `pointer-events: none`. The custom cursor sits above it.
- It should feel like the snow on an old TV: fine grain, flickering, never static.
- **Performance:** don't generate full-resolution noise every frame. Pre-generate a small set of noise tiles once at startup (for example 6–8 tiles of 256 × 256), then cycle through them at a steady rate (about 24 per second) with a random offset each frame. One layer, no per-pixel JS work after startup.
- Strength around 6–8% opacity with a blend mode that suits both the dark room and the light screen. Report the values used, and put them in config.
- `prefers-reduced-motion`: one static noise tile, no cycling.
