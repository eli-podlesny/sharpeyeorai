# Brief: v0.4 — Game flow, persistent HUD, round choreography

## Goal
The game moves the way the owner designed it: the screen is already "alive" behind the doors, the HUD never disappears, and every round has the same intro → play → outro rhythm. Shapes stay the 200 × 200 rectangle in this brief (new shapes are v0.5).

All sizes are in design px (the stage scales everything). Where the owner writes rem, 1rem = 16 design px.

## 1. Screen is live behind the doors
- The `loading` scene ("Initializing" + progress bar) renders inside the screen **before** the doors start opening, so the opening reveals it already running.
- New order: `ready` (doors closed, Start button outside the doors) → loading begins behind the doors → doors open → loading completes → round 1 intro.
- Configure: `loadingStartBeforeDoorsMs` (default 300) and the total loading duration.

## 2. Persistent HUD inside the screen
- Round counter ("Test 04/12"), progress bar and timer live in a `screen-hud` layer **inside the screen, below the doors**. They stay visible for the whole game, including during round intros/outros and the loading state (counter shows 00/12 and the timer shows 0ms there).
- The timer shows the current round's elapsed time and freezes at the click value until the next round starts.
- Counter and timer font: **Kode Mono Bold** (update tokens; Turret Road remains elsewhere).

## 3. Sample tooltip position
- The "Sample 0X, logged" tooltip always appears in the **top-right corner inside the screen frame**, at a fixed position from `layout.config.ts`, no longer next to the click.
- It appears on click, stays through the outro, and disappears when the next round's intro starts.
- The click itself still gets a small marker at the click point (as now).

## 4. Round choreography (`src/rounds/sequence.ts`)
One reusable sequence for every round. All timings in `game.config.ts`.

| Step | What happens | Default |
|---|---|---|
| 1 | "Test #N" (large, Turret Road) fades in at the center of the screen, with the objective text (smaller) directly below it | 400ms fade |
| 2 | Hold | 900ms |
| 3 | "Test #N" fades out; at the same time the objective text moves from the center to its bottom position | 300ms fade, 500ms move, ease-in-out |
| 4 | The shape fades in | 400ms |
| 5 | **The round timer starts only when the shape is fully visible.** Clicks before that are ignored. | |
| 6 | Player clicks: marker + tooltip appear | |
| 7 | Wait | 400ms |
| 8 | Objective text, shape and marker fade out together | 400ms ease |
| 9 | Next round starts at step 1 | |

- Emit events at each step (`round.intro.start`, `round.intro.end`, `round.shape.visible`, `round.click`, `round.outro.start`, `round.outro.end`) for sound and effects later.
- With `prefers-reduced-motion`, replace the moves with instant changes and keep only short fades.
- The latency used for scoring is measured from the moment of `round.shape.visible`.

## 5. End of game
- After round 12's outro: the doors close, the scene goes dark for `endDarknessMs` (default 3000; simple black overlay for now), then the scene returns to normal and the doors open revealing the score screen, which is already rendered behind them.
- The separate "Calculating" scene is removed from the flow (keep the module, unused, in case we bring it back).

## 6. Round timeline hook (preparation for v0.5–v0.7)
- Each round config gets an optional `timeline` hook: functions called on `intro.start`, `shape.visible`, every animation frame while active, `click`, and `outro.end`. Rounds will use it later for moving shapes, glitches and scene effects. Round 1–12 configs leave it empty for now.
- Scene-wide state (normal / distorted / alert / blackout) gets a placeholder `sceneMode` in the state store, changeable from the debug panel, with no visual effect yet.

## Git
Branch `feat/v0.4-flow`, PR, preview link, owner merges, then version `0.4.0` and tag.

## Done when
- Pressing Start: the doors open onto an already-running "Initializing", and round 1's intro follows without a jump.
- The counter, progress and timer are visible the entire game, in Kode Mono Bold.
- The tooltip always sits in the top-right of the screen.
- Every round follows the 9-step sequence. The timer starts only when the shape is fully visible, and clicks during the intro are ignored.
- The game ends with doors closing, 3s of darkness, and the doors opening on the score.
- Tests and build pass. Timings can be changed in config without code changes.

## Out of scope
New shapes, moving/morphing shapes, glitch, background morph, alert, screen drop, blackout effects, real art.
